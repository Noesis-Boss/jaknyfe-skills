# Image Prompt Builder — Canonical Template

Fill every field. Leave nothing blank when shipping.

```
FORMAT:        where it will be posted + aspect ratio

BUSINESS:      what you actually sell

PRODUCT:       the specific thing in this image

BUYER:         who you want to stop scrolling

GOAL:          the ONE job this image does

SCENE:         surface, backdrop, props

COMPOSITION:   placement, shadow, empty space for text

STYLE:         aesthetic + hex color palette

TEXT:          the exact words on the image

BRAND INPUTS:  logo, real photos, real product details

IMAGE RULES:   what the model may never invent

OUTPUT:        resolution + final aspect ratio
```

## Field guidance

- **FORMAT** — Platform + dimensions. e.g. "Instagram post, 4:5" or "LinkedIn banner, 1200×627"
- **BUSINESS** — Your business in 3–5 words. e.g. "Premium cold-brew coffee roaster"
- **PRODUCT** — The one thing in the frame. e.g. "Glass bottle of single-origin cold brew"
- **BUYER** — Specific demographic + psychographic. e.g. "Health-conscious professionals 25-40 who value quality"
- **GOAL** — One sentence. e.g. "Drive online store purchases within 24 hours"
- **SCENE** — Setting + props. e.g. "Sunlit kitchen counter with coffee beans and lime wedge"
- **COMPOSITION** — Visual placement. e.g. "Bottle center-frame, soft shadow, empty left third for text overlay"
- **STYLE** — Aesthetic + exact hex colors. e.g. "Minimalist product photography, matte #000000, warm amber #D4A76A"
- **TEXT** — Word for word. e.g. `"Smooth. Not bitter."`
- **BRAND INPUTS** — Logo placement, real photos, product details the model must use. e.g. "Logo debossed on bottle cap, real condensation on glass"
- **IMAGE RULES** — Hard constraints the model must never violate. e.g. "No floating bottles, no surreal elements, no extra text"
- **OUTPUT** — Exact specs. e.g. "1080×1350, 4:5 ratio"
