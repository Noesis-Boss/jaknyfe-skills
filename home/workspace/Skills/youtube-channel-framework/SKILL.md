# YouTube Channel Framework

Build a launch-ready YouTube channel framework in seven stages.

## When to use

- The user wants to plan, launch, or systematize a YouTube channel.
- The user wants a content strategy for a faceless or personality-driven channel.
- The user wants competitor analysis converted into an original content system.

## Workflow

1. **Niche Evaluation** — audience size, competition density, monetization path, content gap.
2. **Channel Positioning** — unique angle, value proposition, upload cadence, channel architecture.
3. **Content System** — 3 content pillars, repeatable title structures, hook templates.
4. **Script Architecture** — hook (0–5s), open loop, context, value, escalation, payoff, CTA.
5. **Thumbnail + Title** — click-worthy without clickbait; A/B pairings.
6. **Production Pipeline** — scripting → recording → editing → publishing workflow.
7. **30-Day Calendar** — day-by-day upload schedule with topics and format.

## Output format

Markdown report with one section per stage. No invented analytics — if you can't verify a competitor's numbers, label them "estimated" or omit.

## Guardrails

- Never present competitor analysis as original ideas — always separate "what they do" from "what you should do."
- Do not promise view counts or revenue figures.
- Distinguish evergreen content from trend-chasing.
