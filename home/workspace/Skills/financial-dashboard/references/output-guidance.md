# Output guidance

## Spreadsheet

Use separate tabs or sheets for Source, Cleaned Data, Data Issues, Assumptions, Executive Overview, P&L, Cash Flow, Expenses, Receivables, Forecast, and Alerts. Keep formulas linked to cleaned data, freeze headers, format dates consistently, and expose editable assumptions in one place.

## Web dashboard

Use a responsive layout with an executive summary first, then drill-down sections. Show filter state, as-of date, units, and data freshness. Use tooltips for formulas and assumptions. Provide explicit empty, loading, and error states. Test narrow viewport readability and capture a screenshot after the final build.

## Both

Calculate once, render twice. Reconcile headline totals between outputs and show the same scenario assumptions, period, currency, and status rules.
