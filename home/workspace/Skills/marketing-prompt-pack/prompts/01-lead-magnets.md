> Prepend the CONTEXT block + grounding preamble from `SKILL.md` to every prompt.

1. Create a lead magnet concept for [audience] struggling with [problem]. Give me 5 title options, the format (checklist/guide/template/etc.), and an outline of the content.

2. Write a complete one-page checklist lead magnet titled '[Title]' for [audience]. Include 15-20 actionable items grouped into 3-4 sections.

3. Build a 3-day email mini-course on [topic] for [audience]. Write the subject lines and core teaching points for each day.

4. Create a swipe file lead magnet for [niche] with 10 fill-in-the-blank templates they can use immediately. Topic: [topic].

5. Write the copy for a lead magnet landing page for [title]. Include headline, subheadline, 5 bullet points of what they'll get, and a CTA button.

6. Design a quiz lead magnet for [audience]. Write 7 questions, 3 answer options each, and 3 result profiles with a personalized recommendation for each.

7. Create a resource list lead magnet for [niche]. Curate 15 tools, templates, or resources with a one-line description of each and why it's useful.
   - ✏️ Patch: only include tools you are certain exist; mark any uncertain one [VERIFY]. No invented tools or URLs.

8. Write the content for a quick-win guide (3-5 pages) that helps [audience] achieve [specific result] in [timeframe]. Include intro, 5 steps, and a conclusion CTA.

9. Build an ROI calculator or self-assessment lead magnet concept for [audience]. Outline the inputs, scoring logic, and the insight/result they receive.
   - ✏️ Patch: scoring logic must use the formulas I provide or state [NEED INPUT] — no invented industry benchmarks.
