# Facebook Content

> Prepend the CONTEXT block + grounding preamble from `SKILL.md` to every prompt.

1. Write a Facebook post for [brand] that starts with a scroll-stopping first line about [topic], shares a valuable tip, and ends with a question to drive comments.

2. Create a week of Facebook content (7 posts) for [brand] in [niche]. Mix: 2 educational, 2 entertaining, 1 promotional, 1 testimonial, 1 behind-the-scenes.
   - ✏️ Patch: testimonial post requires a real pasted testimonial — [NEED INPUT] if none provided.

3. Write a long-form Facebook post (300-500 words) in the style of a personal story that leads to the insight: [key message]. Use conversational tone and short paragraphs.
   - ✏️ Patch: story must be mine — I provide the raw story beats; do not invent personal anecdotes.

4. Create a Facebook poll + caption for [brand]. Topic: [topic]. Write the question, 4 answer options, and a 50-word caption to introduce it.

5. Write a Facebook Live outline for [topic] that lasts 20 minutes. Include a hook intro, 3 teaching points, audience engagement questions, and a CTA.

6. Generate 5 Facebook post hooks (first lines only) for [brand] that stop the scroll. Use curiosity, controversy, bold statements, surprising stats, or personal confessions.
   - ✏️ Patch: any stat used must come from CONTEXT or be marked [VERIFY]. No invented numbers.

7. Write a Facebook group welcome post for a community about [topic]. Make it warm, set expectations, explain the rules, and prompt members to introduce themselves.

8. Create a Facebook event post for [event/webinar/launch]. Include what it is, why they should care, what they'll learn/get, and how to register.

9. Write a Facebook ad disguised as organic content for [product]. It should look like a personal recommendation, use social proof, and have a native feel with a soft CTA.
   - ⚠️ Hard patch: paid ads must be identifiable. Add "#ad" / "Sponsored" disclosure per FTC rules. "Native feel" ≠ concealed sponsorship.
