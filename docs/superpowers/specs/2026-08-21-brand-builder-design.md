# Brand Builder Skill Design

## Objective

Create a reusable Zo skill that turns the eight uploaded lean-brand prompts into a practical workflow for launching a credible brand quickly.

## Scope

The skill supports a complete sequential workflow and independent stage runs:

1. Essential-only brand scoping
2. One core message
3. Minimum visual kit
4. Single-page site structure
5. Proof-first content
6. Launch-ready copy
7. Go-live checklist
8. Post-launch iteration plan

## Boundaries

`brand-builder` handles lean launch strategy and copy. Existing `brandkit` remains responsible for premium visual board and image-generation work. Existing `brand-positioning` remains responsible for deep personal-brand positioning systems and ongoing positioning refinement.

## Quality bar

Outputs must be truthful, concise, internally coherent, usable without another branding session, and explicit about assumptions, missing proof, and deferred polish.
