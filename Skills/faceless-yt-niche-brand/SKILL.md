# Faceless YouTube niche brand

Use this skill before channel-level scripting. Define one primary audience, the problem the channel solves, the content promise, differentiators, recurring formats, visual and narration rules, evidence standards, and topics to avoid. Return a concise brand brief that downstream video scripts can consume.
