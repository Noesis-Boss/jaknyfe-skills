OpenRig is an open-source tool that turns your AI coding agents from a pile of terminal sessions into one organized, persistent team. If you use Claude Code, Codex, Cursor, Grok, and other coding agents, what’s been missing is a good interface to orchestrate them together. Think of it as a techy Paperclip, built around building rather than general assistant tasks. You can create named specialist agents, like a review agent, and trigger them inside a bigger workflow: build, then check, then call another agent, much like a team of real people. And you choose the best agent for each job: let one model be your builder, and another handle images. Start with a repository and one useful change, then keep the team’s work and context in one place.
