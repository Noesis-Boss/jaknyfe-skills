Andrew Warner and Adam dive into 10 GitHub repos that can make AI coding smarter, simpler, and more useful—from an “I Have ADHD” skill that cuts through AI’s walls of text to tools that improve engineering workflows, reduce code bloat, manage context, and turn Codex into a more capable development environment.

Andrew and Adam break down the most interesting repos of the week, starting with I Have ADHD, which automatically pushes AI to be more concise and easier to understand. They explore ECC, a skill pack that gives AI coders a structured engineering process; Ponytail, which teaches AI to take the simplest possible approach instead of overengineering; and HumanLayer’s skills for packaging repeatable workflows. They also look at Zapier MCP for connecting agents to more than 8,000 tools, OpenAI’s Plugins repository for Codex, Archify for turning code and processes into visual diagrams, and Context Mode for reducing unnecessary context in AI conversations. Along the way, Adam explains why “strategic laziness” can make AI-generated software easier to maintain, why skills can be useful but aren't always necessary, and why OpenAI’s plugin approach may be the next evolution beyond standalone skills.

The episode also features audience submissions, including Reckoner, a dashboard for monitoring AI billing across multiple providers; Tim Harris’s collection of skills designed for people who don't want to read code; Clodex, which lets users swap GPT models into the Claude Code terminal; and AI Marketing Panel, which uses simulated customer personas to pressure-test marketing copy before it reaches real customers. Andrew and Adam also discuss whether future GitHub roundups should skip skills entirely—and invite viewers to share the skills and repos they actually use.
