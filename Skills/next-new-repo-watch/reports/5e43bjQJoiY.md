Tired of paying for Photoshop every month or being locked into proprietary software? PhotoCraft with almost 8,500 stars is an open source clean room reimplementation of Adobe Photoshop written entirely in Rust. It gives you layers, masks, adjustment layers, layer styles, type, vectors, brushes, and real PSD file support in a native app that runs offline. The interface is designed to be familiar so if you know Photoshop you already know PhotoCraft. Everything runs on a GPU compositor for speed, and the project is fully yours to use, modify, and keep forever. No cloud, no subscriptions, no tracking.
