Andrew Warner sits down with Paul Bakaus, creator of Impeccable, to show how this free, open-source tool helps AI coding agents create more distinctive, polished, and functional website designs.

Instead of settling for generic AI-generated websites, Impeccable critiques your design, asks about your goals and target audience, explores different visual directions, and helps you refine the results through live visual feedback. Paul demonstrates how to generate design variations, edit elements directly on a development server, draw annotations, add new sections, and improve websites using design systems and reusable visual styles. The conversation also explores how Impeccable works with Claude Code and Codex, detects common AI design patterns, and makes better design accessible to developers building with AI.
