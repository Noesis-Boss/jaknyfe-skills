You're tired of diagrams that look inconsistent or rely on messy Mermaid charts that never quite match your brand. Diagram Design with almost 53,000 stars turns your agent into a diagramming pro, making clean, self-contained HTML and SVG files with no shadows and zero Mermaid slop. You just tell your agent what you need, like an architecture diagram or a quadrant chart, and it picks the right type from 45 options, states its plan, and writes one HTML file you can open by double clicking. It works with hosts like Cursor, Claude Code, and GitHub Copilot. You can even point it to your website to pull your palette and fonts so every diagram matches your look. Install it with npx skills add and start designing.
