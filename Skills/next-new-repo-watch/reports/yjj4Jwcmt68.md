Here are 35 projects that caught developers' attention in October. You'll recognize a few from earlier episodes, but this time the month's biggest finds are all in one place. Let's get into it. Clean your TV helps you clean up an Android or Google TV and replace its crowded home screen with a simple app dock. It connects over Wi-Fi, backs up your settings, and can disable pre-installed apps and ad services you don't want. You can use a coding assistant to guide the setup or do it yourself. The project also includes a restore tool if you change your mind. DeepSeek has open-sourced part of the system it uses to run its AI models at scale. Deep Infer handles things like batching requests, distributing work across accelerators, and generating structured outputs such as JSON. The release runs DeepSeek V4.1 flash offline on supported Nvidia and Huawei hardware. You'll still need to build extra store components to turn it into a complete online service. Anatomy is an agent skill that draws interactive isometric illustrations of machines and complex systems with no NPM dependencies at all. You give it a concept, and the agent gathers real numbers, invents a physical object that shows how it works, then builds it with a drawing kit. The result is a shaded SVG with live readouts and smooth motion, plus optional WebGL effects for fire, water, and light. Harness Squared from Google Research improves everything around an AI model, from prompts and tools to memory and skills, while leaving the model itself untouched. For each task, it proposes changes to the harness, tests them, and keeps whatever behaves best, with no answer key needed. Lessons from those runs are saved, so later tasks start from a better harness. OpenAI's math repository is a public dump of research manuscripts written by an unnamed internal model used to test it on open problems in mathematics. The model was given about 4,000 problems and averaged around 3 hours of thinking on each result it kept. That produced 721 manuscripts across 373 problem families, all in PDF and LaTeX. Wordcraft is an open-source word processor written in Rust, a clean room rebuild of the classic desktop word processor. It opens and saves .docx files, reads old .doc files, and exports to PDF. It handles styles, tables, track changes, comments, and mail merge with spelling and grammar checks that work offline. The interface draws natively on the GPU, and the same app can even run in your browser through WebAssembly. GPU Unlock is a Linux kernel module that lifts a cap Nvidia places on the Tensor cores of its GeForce cards. On these cards, FP16, BF16, and TF32 matrix math runs at half the speed the hardware can do. The module loads at boot before Nvidia's own driver and removes that limit without a patched driver or a VBIOS flash. It's stable on RTX 30 cards and experimental on the 20 and 40 series. Replica Skill is a set of 11 Claude skills that study an existing app and rebuild its features as a new product of your own. They run in order from recon and architecture to design, build, back-end, testing, and deploy, each picking up where the last one left off. It's clean room copying features and flows, but never code, logos, or text, and it scores how close your version's features get to the original. Dig Up is a macOS menu bar app that finds files on your Mac by describing what's in them, built on Google DeepMind's embedding Gemma 2 running locally through llama.cpp. Search in plain words in more than 100 languages, and it pulls up the matching photo, document, or code, even the exact page of a PDF. It can jump straight to the right moment in a video or podcast. The Everything Project from the team behind Pyuter is a single repo that sets out to rebuild the world's common software from scratch as open source. It holds about 40 apps in one place. Office tools like a spreadsheet, documents, and slides, creative tools for photos, video, vector art, audio, and 3D, plus CAD, circuit design, a CRM, accounting, and invoicing. There are even games like chess and Sudoku. Free my TV replaces the ad-filled home screen on Google TV and Android TV with a clean one built as a plain Android app with no outside libraries. Your chosen streaming apps sit on a glass shelf. Every hour it shows three trending picks, but only from apps you already have split into movies and shows. You also get the hourly weather, sunrise and sunset, and a screensaver with a big clock. Ubee mode is a coding agent skill built around Uncle Bob's software engineering principles. It tells your agent to think through the problem, write tests, fix root causes, and refactor as it goes. It also works with companion tools that check code complexity, find duplication, and run mutation tests to see whether your tests catch broken behavior. The goal is to give your AI coding sessions a bit more discipline. Horizon is an unofficial rewrite of Minecraft Java Edition in Rust rendering with WebGPU and Vulcan. It contains no Minecraft code or assets. Its launcher builds everything from your own copy of the game. It reads the same worlds, generates the same terrain, and runs the same mobs and redstone checked against the original by differential test harnesses. DSBot is a community plugin for Deep Seek Harness that lets you build a team of long-lived AI bots that remember things. A main bot called the chief runs things, and you can drop several bots into a group chat with one acting as admin. Each bot gets its own memory and its own choice of model. They hand work off to each other and share one library of MCP servers and skills. ESP32 iPhone agent lets an AI model use a real iPhone with a board that costs about $7 as its hands. The phone mirrors its screen to a computer over AirPlay, which is how the model sees it. The ESP32S3 board plugs into the phone as an ordinary USB mouse and keyboard, and assistive touch turns every click into a tap. One model plans the steps toward your goal, and another picks each next move from the latest screenshot. Pella is a tiny library from the Obsidian team that turns Mermaid diagram text into SVG with no dependencies at all. It supports every diagram type in Mermaid 12.1, but draws them with its own layout and visual style. Rendering happens instantly and synchronously, so there's nothing to wait for. Colors and fonts come from CSS variables, so a theme change shows up without redrawing the diagram. Zero Breach Toolkit checks your devices for traces of known spyware, including Pegasus and Predator. It can scan computers, analyze data collected from Android phones, and check iPhone backups. The scan runs offline and produces a report showing what it found and what it couldn't check. A clean result doesn't prove a device is safe, but it can help you decide what needs a closer look. Open Film is an open-source tool that lets coding agents like Claude, Code, and Codex make videos as web pages. Every shot is a page with one function that draws the picture at any moment in time, and an HTML timeline lines the shots up into tracks. The same moment always draws the same frame, so renders come out identical every time. A local editor called Studio lets you tweak things by hand or just ask the agent. Lean REA is a tiny agent skill, just one 8 kilobyte file for reverse-engineering apps and binaries, built as a lighter alternative to the REA toolset. It doesn't add an MCP server at all. Instead, it tells your agent which ordinary command line tool fits each kind of target, from electron app archives to macOS binaries, Go programs, Android apps, and WebAssembly. Daytrader is a set of 11 Claude skills for practicing day trading on US stocks, written in plain Python using free public data. The skills hand off to each other. One scans charts, another watches the news, then others time your entry and exit, size the position, and check it against your risk limits. Paper trading is on by default, and nothing places an order until you approve that exact trade. Earshot gives coding agents the ability to understand sound, running on the CPU as a command line tool, a Python API, or an MCP server. It describes what a recording sounds like in plain words, scores how well a sound matches a description, and finds the best moments in a long clip. It can check sound against video cuts, tell a real recording from a synthesized one, and even write code that recreates a sound effect. CC Baga is a desktop toolkit for managing multiple local Claude workspaces. You can archive one identity, switch to another, and choose which settings and conversation history stay with each one. It also includes a separate browser profile and tools to check whether your browser's language and time zone match your network location. It works on Windows, Linux, and Apple Silicon Macs. Ali brings AirDrop to the Linux, so you can send photos and files directly between your computer and an iPhone. Your Linux machine can show up in the iPhone's share menu, and it can send files back, too. It works with a range of Wi-Fi cards, though compatibility varies. On some cards, your regular Wi-Fi connection pauses during a transfer, so check the hardware list first. Hairline gives your website a collection of interactive line illustrations that respond to your cursor. Hover over a keyboard, and the keys sync. Move across a phone and its layers pull apart. There are more than 30 figures and you can adjust their colors and how strongly they move. It works with React or plain web projects and there's a coding agent skill for creating your own. Tendero is a macOS app that hangs your screenshots on a little clothesline at the top of the screen instead of piling them on your desktop built in Swift. Rest your pointer in the menu bar and the line slides down with your latest shots. Click one to copy it, hold to mark it up, or double click to open it in preview. Drag a screenshot into any app to drop in a copy or into a folder to take it off the line. OXR turns messy PDFs and document images into data your AI tools can actually work with. It picks out text, tables, formulas, and even chemical structures, then exports the results as markdown or JSON with their positions on the page. You can try it through an online demo or run it yourself on a supported Nvidia GPU. You can also swap in your own layout model for different kinds of documents. NetMerge combines several internet connections at once like your Wi-Fi, Ethernet, and a phone hotspot so your apps use all of them together. It's a single go program that creates a virtual network adapter with no account, no server, and no VPN. Each new connection goes out over one of your links with faster links getting more and a dead link stops getting traffic until it recovers. TSRS is a Rust port of the TypeScript 7 type checker from the oxc project built to be a drop-in replacement for the official compiler and language server. It aims to match TypeScript's results exactly while using far less memory. Install it with PNPM and run it just like TSC or hook it into your editor as a language server. There's also a web assembly build that runs in Node and in the browser. Git AI is an open-source version control system designed for lots of coding agents working on the same project. Instead of each agent downloading the whole repository, it can fetch just the files it needs. It batches changes headed for the same branch, keeps a record of which agent made each update, and can use a resolver to propose fixes for merge conflicts. It's based on a design Anthropic described called Scion. Muse gadgets lets you build your own devices that connect to the Muse app. Grab an ESP32 board or a Raspberry Pi, add a screen, buttons, or sensors, and use the SDK to make them work together. You could turn a spare Pi into a gadget for controlling your home assistant setup. The code and firmware are open source, though you'll need an SDK token to pair a device. 3D model anything, from West Boss, turns a scan of a room into an editable 3JS scene with an AI agent doing most of the modeling. You capture the room with an iPhone app that records lidar depth and photos. Then a skill walks the agent through measuring the space, building the model, and comparing it against your real photos from the same camera angles, over and over, until it matches. T-stack is Theo's own set of agent skills for Claude code and Codex, cleaned up so anyone can use the ones he relies on every day. Each skill fires from a simple phrase. Say, "Full send." and an agent proves a change works, gets it reviewed, files the pull request, watches CI and the review bots, then merges. Say, "Council." and you get a second opinion on your change from models built by other companies. Manim GX lets you create animated math explainers and 3D videos using Python. It follows Manim's API, but uses a Rust rendering engine that runs on your GPU. You can combine equations and graphs with 3D objects and moving cameras, then export the result as a video. It also works in the browser, and a coding agent can help you write and check the scenes. Hatch Zip helps you unpack large archives when your drive is nearly full. It extracts the files while shrinking the original archive, freeing up space as it goes. It supports formats like zip, 7z, RAR, and tar. And it checks whether the extraction will fit before starting. The archive is used up during this process, but you can choose to keep it if you have enough space. Brutal is a C# framework for developers who want to build a game or even their own game engine. It gives you building blocks for graphics, physics, audio, and networking, while leaving the bigger design decisions to you. It's already the foundation beneath Kitten Space Agency and RimWorld's Waylith engine. There's no built-in editor or renderer, so expect to do some hands-on work.
