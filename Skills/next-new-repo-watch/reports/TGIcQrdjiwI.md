Ever wanted your own chat app but dreaded wiring up accounts, groups, private messages, and realtime updates from scratch? Fiora, with almost 8,000 stars, is an open source chat application built with Node.js, React, and Socket.IO. It gives you a complete stack including backend, web frontend, and mobile apps, so you can run it on Windows, Linux, or macOS. You can register an account, create or join groups, chat privately, and add friends. Messages support text, emoticons, pictures, code, files, and commands, and there is search for emoticons too. It follows the MIT license and the online demo and docs make setup easier to explore. If you need a familiar Slack style chat for a community or team, Fiora is a solid place to start.
