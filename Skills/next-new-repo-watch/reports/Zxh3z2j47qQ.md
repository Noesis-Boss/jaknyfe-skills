Ever tried to reverse engineer an Android app only to get lost in obfuscated Kotlin code and missing HTTP endpoints? The Android Reverse Engineering Skill for Claude Code with almost 8,030 stars, recovers original Kotlin class names that R8 cannot strip and extracts APIs from tools like Retrofit, OkHttp, and even Ktor and Apollo. It decompiles APK, XAPK, JAR, and AAR files to find Retrofit endpoints, OkHttp calls, hardcoded URLs, and authentication patterns. This helps you document and reproduce an app's backend without the original source code. It also supports Windows through experimental PowerShell scripts. A practical addition for any developer working on Android security or API analysis.
