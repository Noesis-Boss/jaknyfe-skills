HyperFrames is a free, open-source, code-based video generator from HeyGen. Video generation is hard and expensive, but HyperFrames takes a different approach: an AI agent writes code to create all the animations, so everything is programmatic. When you want to make a small change, you don’t have to regenerate every frame. You just update the original code, and HyperFrames re-renders the video for you, almost like a screen recording of the animation. In short, agents write HTML and it plays that HTML as an MP4. It’s built for AI coding agents, so you can hand the work off instead of wrestling with a traditional video editor.
