Tired of juggling a dozen free AI providers, each with their own API keys and rate limits? FreeLLMAPI with almost 35,000 stars, wraps 34 free LLM providers and 635 model endpoints behind a single OpenAI-compatible API. It handles smart routing, so requests go to the best available model, and if one provider rate-limits you, it automatically fails over to the next. Keys are stored encrypted, and per-key usage tracking keeps you under free-tier caps. You can even add custom OpenAI-compatible endpoints for chat, embedding, image, and audio. The model catalog updates from a signed feed, so new providers and quota changes appear without a git pull. It's built for personal experimentation, not production, and has a free tier with a monthly snapshot. Great for exploring LLMs without spending a dime.
