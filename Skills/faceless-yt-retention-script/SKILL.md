# Faceless YouTube retention script

Use this skill to define the channel-level structure before writing an individual video script. Produce the audience promise, opening hook, time-coded beats, open loops, transitions, pattern interrupts, payoff, and CTA. Keep each beat tied to a visual change or new information.
