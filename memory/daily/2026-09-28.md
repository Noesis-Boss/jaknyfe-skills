# 2026-09-28 — `hyperframes init` symlink fanout: audit, correction, cleanup

**What:** Followed up on the one unresolved finding from the 2026-09-27 `openai/plugins` trial — the
note that `hyperframes init` is not sandboxed and symlinks its workflow skills into agent skill
directories across `/root`. Goal was to answer "what could actually call them" and restore `/root`
to its pre-test state.

**The count was wrong.** The 2026-09-27 note said "~530 symlinks across 53 directories." The
directory count (53) was right; the link count was not. The first inventory swept
`find /root -maxdepth 4` and missed 11 links under `/root/.pi/agent/skills` at depth 5.
Correct figure, swept at `-maxdepth 6`: **635 symlinks across 53 directories**, plus **11 empty
placeholder directories** created at `/root/.claude/skills/<name>/`.

**What could call them: nothing.** Every placeholder under `/root/.claude/skills/` is an empty
directory — 0 files. So the 635 links resolve to directories with nothing behind them; no agent
runtime can load a skill from them. Confirmed against the runtimes actually installed on this host:
6 binaries present (`hermes`, `kilo`, `kilocode`, `codex`, `claude`, `opencode`), 3 of those with a
running process (`hermes`, `kilo`, `openclaw`). All three have a `skills/<name>/` entry for the
hyperframes workflows, and every one of them is inert. `zcode` — named in the original note — is
not installed at all, so it could never have been a consumer. A second, older **~795-link fanout
dated 2026-08-18** points at the same empty placeholders; that is pre-existing platform state, not
from this run, and was deliberately left alone.

**Cleanup.** Removed all 635 links, mtime-gated to links created on the run day so the 2026-08-18
fanout survived, symlinks only — never `rm -rf` — then `rmdir` for the empty placeholders (which
`rm` would have refused on anyway). Verified 0 remaining from the run. Only one placeholder
(`/root/.claude/skills/media-use`) was still on disk; the other 10 were already gone.

**Recorded in three places:** the undo command block and the `-maxdepth 6` sweep warning in the
Zo router `Skills/hyperframes/SKILL.md`; the corrected figure and the "what could call them:
nothing" finding in `Skills/TRIAL-openai-plugins.md`; and a dated correction sub-bullet under the
2026-09-27 Feature Log entry in `AGENTS.md`. The 2026-09-27 daily note is left as written — the
correction lives in AGENTS.md as the canonical record.

**Tangent left alone:** four pre-existing dangling symlinks in `Projects/paperclip-agent/`, dating
to the paperclip deletion. Out of scope; paperclip is deprecated by owner directive.
