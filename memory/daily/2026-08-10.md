## 2026-08-10 (evening) — Ollama proxy derailment FIXED

**What happened:** TimelineBuilder skill work (Knights Templar / Jacques de Molay timeline) derailed into microplastics research after a "continue" — classic proxy context truncation.

**Root cause:** Ollama default num_ctx=4096; prompts longer than loaded context are truncated from the START → system prompt + early turns silently dropped → model invents new task mid-chat. Only happened via proxy because proxy was the only path serving long multi-turn prompts to Ollama.

**Fix (all applied 2026-08-10):**
1. `ollama-server` service env: `OLLAMA_CONTEXT_LENGTH=32768` (was unset → 4096)
2. `proxy.ts`: forces `options.num_ctx=32768` on every Ollama-backed request (Bonsai excluded, runs -c 2048)
3. Proxy timeouts raised: `PRIMARY_TIMEOUT_MS=120000`, `REQUEST_TIMEOUT_MS=360000` (CPU can't process 4-5k-token prompts in 25s)
4. `ADHD_STYLE=true`, `FALLBACK_MODELS=gemma3:4b` set explicitly on service env

**Verification:** loaded models show `ctx: 32768` (`/api/ps`); code word "PLUM-42-ORCHARD" planted in turn 1 survived a ~4.6k-token turn-2 conversation through the proxy (would be destroyed at 4096). 1b run: 42s.
