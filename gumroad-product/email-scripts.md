## Script 1 — Scope Confirmation After Kickoff

**When to use:** Within 24 hours of your client kickoff meeting.

**Subject:** Project Brief — Please Review Before We Start

Hi [Client Name],

Thanks for the kickoff — excited to get started. Before I dive in, I want to make sure we're aligned on everything we discussed.

Based on our conversation, here's my understanding of the project:

- **Deliverables:** [list]
- **Timeline:** [milestones + final delivery date]
- **Revisions included:** [X rounds]
- **What's NOT included:** [known scope boundaries]
- **Investment:** [$X]

If anything looks off, now's the time to flag it — I can only honor the scope we've locked in. Once we're aligned, I'll send over the project tracker link so you can follow progress in real time.

Sound good?

[Your Name]

## Script 2 — Add-On Pricing Request

**When to use:** When a client asks for work outside the original scope.

**Subject:** Re: [Project Name] — New Request

Hi [Client Name],

I love that you're thinking about this — [brief acknowledgment]. I want to handle this right so it doesn't impact your timeline.

The [feature/change] you're describing falls outside the original scope we agreed on, which means it needs to be scoped as an add-on. That way we keep the original project on track without any surprises.

Here are the options:

- **Add-on option A:** [description] — +[$X]
- **Add-on option B:** [description] — +[$X]

Happy to adjust the timeline or phase this however works best for you. Just let me know how you'd like to proceed and I'll get it on the schedule.

[Your Name]

## Script 3 — Revision Limit Reminder

**When to use:** When the client has used [X] of their [Y] included revisions and is submitting more feedback.

**Subject:** Re: [Project Name] — Revision Count

Hi [Client Name],

Thanks for the feedback — I've reviewed everything. Before I dive in, I wanted to flag where we are:

You've used [X] of your [Y] included revisions. The feedback you've shared looks like it touches on [brief description], which represents [a significant revision / additional rounds] beyond what was included.

A few options:

1. **Narrow the scope:** I can incorporate your feedback within the existing rounds if we focus on [specific priority].
2. **Add extra rounds:** [+£X] per additional round of revisions.
3. **Phase it:** I can include this in the next project phase / version 2.0.

I'd love to keep this moving — just want to make sure we're both set up for success. What feels right?

[Your Name]
