## Step 1 — Gate everything on IRS transcripts (this week)

Do NOT file $0 returns until this is done. The LLC's income question is answered by records, not by assumption.

1. Create/log in to an IRS Online Account at irs.gov (owner identity, EIN holder).
2. Pull the entity's account transcripts for 2021–2025 (IRS Online Account under the EIN, or Form 4506-T checked for "Account Transcript", EIN 23-2xx… — 4506-T goes to the entity, signed by a responsible officer).
3. Read the result:

   - Transcripts show no filings and no reported income → file zero-activity 1065s (Step 2).
   - Bank/merchant records show income (the "<$500/yr" payments) → file with the actual amounts. A $0 return that contradicts bank deposits is a bigger problem than a late return. Penalties for late filings of near-zero-income partnerships are small; false returns are not.

Time: 1–2 days (transcripts by mail take 5–10 days; online same-day if EIN is enrolled).

## Step 2 — Prepare and file the returns (the week after)

Per year, 2021–2025, one Form 1065 packet each:

- Form 1065, page 1 + Schedule B + Schedule K
- Schedule K-1 (1065) for the single member — done as a partnership return, not S-corp/disregarded
- Balance sheet + income statement (Schedule M) — "inactive, no assets, no liabilities" statement if zero-activity
- Zero-activity returns still need the form, schedules, and K-1s filed — a "we did nothing" letter does not satisfy the code

Filing route: paper to IRS (Ogden UT for AZ partnerships without a balance sheet over threshold), or a $100–150/yr e-file through a CPA/TaxAct-for-partnerships style service. For five years of dormants, paper is fine.

## Step 3 — Penalty exposure (attach with first return)

- Standard: 195/month/partner, 12-month cap = $2,340/yr worst case; but for a dormant/near-zero partnership this is routinely abated.
- First-time abatement (FTA): request on the first delinquent year if prior compliance is clean.
- For the rest, attach a reasonable-cause statement: single-member AZ LLC formed 2021 for a low/no-revenue consulting practice; no partnership returns were filed because the owner believed pass-through reporting on Schedule C/E covered it; income never exceeded nominal amounts. This is a common, well-documented abatement ground.
