# Opportunity 3: Agent Skills Packaging & Distribution Tooling
**Recorded:** 2026-09-06 · Paper only · Sources as cited

## The wedge
A CLI + registry for packaging SKILL.md-based agent skills and syncing them across 45+ AI coding agents (Claude Code, Cursor, Codex, etc.) — "write once, install everywhere" for the agent-skills ecosystem.

## Evidence for
- Ecosystem is real and fragmented: skills.sh (Vercel), LobeHub marketplace, vskill, prompts.chat registry, and ai-skills CLI (sync engine for 45+ agents) all coexist. [avikmukherjee.me](https://avikmukherjee.me/blog/ai-skills-registry), [lobehub.com](https://lobehub.com/skills/maxcarlson-scripts-agent_skills)
- Don has 300+ skills in a personal repo and already publishes to a skills registry — he is the ICP and has distribution instincts. (Workspace state, 2026-09-06; no external source needed for self-fit claim.)

## Evidence against
- Vercel (skills.sh) and LobeHub have brand, traffic, and engineering; a solo CLI competes on nothing they lack. [avikmukherjee.me](https://avikmukherjee.me/blog/ai-skills-registry)
- No evidence of paid willingness in this segment — every observed distribution layer is free. Same source.
- Skills spec (agentskills.io) is converging; platform vendors may absorb sync natively. [lobehub.com](https://lobehub.com/skills/maxcarlson-scripts-agent_skills)

## Verdict (S2 input)
Icp fit is great, competitive moat is not. **Not the pick** — retained as comparison.
